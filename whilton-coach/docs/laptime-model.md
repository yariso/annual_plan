# What the physics says: fastest possible laps at Whilton Mill

Generated by `model/laptime.py`. Every number here is a model output built on estimates; nothing was measured at the circuit. Read the caveats at the end before quoting any of it.

## How the model works

- The track is the traced centreline in `data/data.json`, resampled to 1 m, scaled so the International with the chicane measures the 1054 m in the 2025 regulations (checked against the owner's map to half a metre). The usable width is the track width minus the kart minus a margin, so the line may run out to 3.1 m either side of the centreline.
- Heights are a smooth curve through values set at each corner from the written guides (the climb from Crook to Christmas, the drop through the kink and Inkermans to Ashby, the hairpin and Zulu running down the hill). The height of the hill is a parameter, 8 m by default, and is swept.
- The kart is a point mass with a friction ellipse: cornering grip sets the speed the tyres allow through each metre, the engine and the driven rear axle set how hard it can accelerate, the rear-only brakes and the slope set how hard it can slow. Drag and rolling resistance act throughout, gravity along the slope adds or takes away.
- For any given line the fastest speed profile is found by a forward pass (acceleration) and a backward pass (braking) on the closed lap; the lower of the two at each point is what a perfect driver could do.
- The racing line is a smooth curve of sideways offsets at control points every 8 m, kept inside the track. The lap time is minimised, then the search restarts from the best line with a random shake, again and again, until five rounds in a row bring no gain. The round-by-round record is in `data/model.json`.

## Caveats

- No height, width or length of the circuit has been measured for this model. The hill is a guess from words like "up the hill" and "downhill", the width is the usual kart-circuit width, and the length is disputed between 1054 m and 1200 m.
- The kart's grip, traction and braking are estimates. A real hire kart also has a driver-dependent clutch, tyre temperature and a rev limiter the model does not know about.
- A point-mass model has no yaw dynamics, no load transfer beyond what the grip figures assume, no kerbs and no traffic. It shows where time is won and lost and roughly where to brake; it does not know how the kart feels.
- Because of all this, the relative results (which corners cost most, how much the line is worth, how the hill moves the brake points) are worth more than the absolute lap time.
