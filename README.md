# annual_plan

Projects in this repository:

- `whilton-coach/`: Whilton Mill kart line guide and in-ear GPS audio coach. See `whilton-coach/README.md` and `whilton-coach/CLAUDE.md`.
- `chilwell-test/`: the car practical driving test at the Nottingham (Chilwell) test centre: the roads on a map, the rules, what the examiner marks, the manoeuvres, and a mock test the passenger marks. See `chilwell-test/README.md` and `chilwell-test/CLAUDE.md`.

Both are single self-contained web pages built from JSON data. The GitHub Pages workflow
publishes the kart coach at the site root and the driving test guide at `/chilwell/`.
